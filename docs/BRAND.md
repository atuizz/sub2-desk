# Sub2 Desk 品牌说明

Sub2 Desk 是面向兼容 Sub2API 后端的独立桌面式 Web 控制台。它把多窗口、Dock、文件拖入、账号分屏和可恢复操作组织成一套更接近桌面应用的工作流。

## 定位

对外名称使用 **Sub2 Desk**，副标题使用“独立的 Sub2API 桌面式控制台”。Sub2API 是兼容后端和上游项目名称，不表示本项目是 Sub2API 官方客户端；macOS 是交互参考，不表示本项目由 Apple 制作、认证或背书。

## 视觉语言

- 桌面、窗口、Dock、交通灯、浅深色和液态玻璃用于表达熟悉的桌面交互。
- Sub2 Desk 品牌标识使用独立的蓝色玻璃渐变、白色 S 形工作台线和琥珀色状态点。
- 从1.1.1起，`public-release`与本地体验使用同一套图标与壁纸；网站保留Sub2 Desk品牌。素材来源与权利说明见NOTICE.md，不将第三方素材归入项目原创声明。
- 业务内容区域优先可读性和状态清晰度，不把所有表格和表单做成装饰性透明玻璃。

## 文案

推荐写法：

> Sub2 Desk 是兼容 Sub2API 的独立桌面式控制台。

避免写法：

- Apple 官方客户端
- Sub2API 官方桌面版
- 完整替代官方客户端
- 支持所有支付、OAuth、邮件供应商并已全部验收

功能支持和真实验收边界以 README、CHANGELOG 与发布说明为准。品牌调整不改变后端 API 契约，也不改变 Sub2API 的许可和商标归属。
