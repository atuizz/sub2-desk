## 本地体验

本轮保留 Vite 在 `http://127.0.0.1:5179/`，组件预览为 `http://127.0.0.1:5179/?ui-lab`。

重启方式：

```powershell
pnpm --filter @sub2-mac/console dev --host 127.0.0.1 --port 5179
```

把 `packages/sub2-console/.env.example` 复制为同目录 `.env.local`，设置 `SUB2API_DEV_TARGET` 后重启 Vite。实际登录和业务数据需要兼容的原版后端。

生产静态产物位于 `packages/sub2-console/dist/`，交付压缩包位于 `output/releases/sub2-mac-frontend-20260908.zip`。通过 HTTP 静态服务托管，不能双击 HTML 代替服务；生产环境需将 API 路径交给原版后端，Vite 的开发代理不会进入静态包。
