## 交付范围

desktop 包保留用户选择的既有macOS素材和重新设计的业务图标；release 包采用原有独立可分发素材。两者使用相同业务源码，视觉素材不同。既有素材未核实授权，desktop包不是可直接公开再分发的素材许可承诺。

源码不含后端二进制、数据库、真实配置、运行日志或测试账号。启动方法见README和scripts/start-desktop.ps1。

## 真实版本检查证据与限制

此前主任务在本机管理员界面读到运行0.2.1、可用0.2.4和发行说明，证明当次真实版本查询成功。并未执行安装、回滚或重启。M04文档中的“未调用受保护接口”仅描述子任务自身范围，不应否定主任务的随后结果；当前没有据此承诺后端升级全过程通过。

OAuth、Passkey、复杂验证码/协议、内嵌支付SDK及部分高级运营能力仍按UPSTREAM_PARITY逐项迁移。官方完整控制台入口保留，但不计作桌面原生覆盖。邮件送达、真实TOTP变更、配置写入、支付和Docker目标部署仍需独立验收。
