菜单栏四个点击区域改为原生按钮，补可访问名称和焦点，移除重复美元符号；开放页面缩放。账号桌面表格行高从84px降为66px。新增MacSheet可选草稿关闭保护，账号、批量授权、商业编辑及支付提供方复用；它不代表整个系统所有弹层或关闭主窗口均已具备脏表单保护。顶部现有背景位移及Dock材质保留。
