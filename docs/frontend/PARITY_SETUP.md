# F15 · 首次安装向导

2026-09-12：前端流程已实现，真实安装未执行。

## 实现

- `/setup`独立根页；读取官方`/setup/status`，已安装显示登录入口，状态失败只提供重试。
- 数据库、Redis、管理员、最终确认四步；数据库SSL与Redis TLS分别配置。
- 测试通过绑定连接参数快照，修改后失效；迟到响应不把新参数标为已验证。
- 正式安装前再读安装状态，显式确认监听地址/端口/模式。独立前端默认后端端口8000，不误用Vite端口。
- 只提交一次安装；网络中断或响应异常后查询安装状态，避免重复初始化。30次有界轮询，超时可手动重查；卸载终止请求/计时器。密码不持久化，提交后清除。
- API有30秒超时与严格状态响应校验。Vite/nginx只代理四个精确setup API子路径，`/setup`仍由SPA呈现。
